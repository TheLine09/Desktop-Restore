# 桌面布局还原工具 - 使用说明

一个绿色单文件小工具，用来**记录**桌面图标的位置，并在图标被打乱后**一键还原**。

## 文件说明

| 文件                   | 说明                                       |
| ---------------------- | ------------------------------------------ |
| `桌面布局还原工具.exe` | 主程序，双击即用，无需安装（单文件绿色版） |
| `Layouts\`             | 布局存档文件夹，每个布局一个 `.json` 文件  |

## 快速上手

1. **记录布局**：整理好桌面后，填一个布局名（如 `常用布局`），点 **「保存当前布局」**。
2. **还原布局**：桌面被弄乱后，在下拉框选中布局，点 **「还原所选布局」**。

## 还原时三种情形的处理规则

| 情形                               | 处理方式                                          |
| ---------------------------------- | ------------------------------------------------- |
| 图标记录过、现在还在桌面           | 自动移回记录时的位置                              |
| 图标记录过、现在已删除/丢失        | **直接留空**，不影响其他图标                      |
| 桌面上新出现的图标（记录中没有的） | 自动移入桌面新建的 **`新增图标_日期时间`** 文件夹 |

补充说明：

- 「此电脑」「回收站」等系统虚拟图标无法移入文件夹，会保持原位并在日志中列出。
- 上次还原产生的 `新增图标_xxx` 文件夹不会被重复整理。
- 还原完成后会弹窗汇总：还原 / 留空 / 移入 / 未移动 / 未精确 各多少个。

## 双屏 / 多屏切换（v4 新增）不一定精准，建议单屏切换为双屏后再保存一份布局。

单屏 ↔ 双屏切换后，系统会重排图标、坐标系也会变化，绝对坐标天然失效。  
工具的处理方式：

- **保存布局时记录显示器指纹**（虚拟屏范围 + 每台显示器的矩形）；
- **还原时自动判断**：
  - 显示器布局与存档时一致 → 精确还原（逐像素）；
  - 显示器数量一致但排列变化 → 按各显示器比例一一映射；
  - 显示器数量变化（如单屏 ↔ 双屏）→ 整个布局按比例映射到主屏工作区，  
    保证所有图标可见、相对排列保持不变；
  - 旧版存档没有指纹信息 → 先尝试精确还原，若大面积失败自动切换自适应映射；
- 校验改用**半个图标格的容差**（配合网格吸附），僵直期后自动补校验。

> 提示：切屏后如果想要精确的双屏摆位，建议在当前显示器布局下重新  
> 「保存当前布局」一份，以后在该布局下还原就是逐像素精确的。

## 大量图标下的精确性保障（v3）

针对图标很多时的还原不精确问题，还原算法做了五层保障：

1. **先清场**：只把「正压在目标格子上」的杂散图标挪到屏幕右下角，腾出格子  
   （目标格被占是"还原不精确"的主要原因），其余图标一律不动；
2. **同名图标稳定配对**：按坐标排序后顺序配对，同名图标（如两个同名快捷方式）  
   不会互相覆盖或错位；
3. **多轮校验修复**：落位后自动重新枚举核对，有偏差就再修（最多 10 轮），  
   连续 3 轮零进展才判定无法精确（应对系统短暂"僵直"）；
4. **失效图标防御**：已删除文件的桌面缓存残留项可能导致批量操作崩溃，  
   程序会自动定位并跳过这些坏项，不影响其他图标；
5. **视图异常容错**：桌面视图缓存错乱（图标总数虚高等）时逐项容错枚举。

实测：148 个图标全量随机洗牌（含负坐标/超远坐标）→ 还原，147/147 个名字  
全部精确；emoji/200 字超长名/多点名/韩日文/特殊符号等极端文件同样精确；  
删除文件后正确"留空"，新增怪名文件正确移入文件夹。

## 重要注意事项

> ⚠️ **还原前请先关闭「自动排列图标」和「将图标与网格对齐」**  
> （桌面右键 → 查看），否则系统会强制重排，坐标无法生效。  
> 程序启动时会自动检测并提示自动排列是否开启。

- 图标按**显示名称**匹配。同名文件可能被视为同一图标（建议桌面避免重名）。
- 换了显示器分辨率/接了新显示器后，旧布局坐标可能超出屏幕，还原效果会打折扣。
- 保存的布局是当时的快照，重新整理桌面后记得**重新保存一份新布局**。
- 布局文件是普通 JSON，可用记事本打开查看/手工微调坐标。

## 其他功能

- **预览当前桌面图标**：列出全部图标名称和当前坐标，方便核对。
- **打开布局文件夹**：直接跳到 `Layouts\`，方便备份/拷贝布局。
- **删除布局**：删除选中的存档（有确认提示）。
- **自检模式**：命令行运行 `桌面布局还原工具.exe --selftest`，  
  会自动做一次"读取→移动→复原"测试，结果写入 `selftest.log`。

## 常见问题

**Q: 点了还原但位置没变？**  
基本是「自动排列图标」没关。另外「对齐网格」会把坐标吸附到网格，位置可能略有偏移。

**Q: 杀毒软件报毒？**  
工具通过 COM 接口操作系统桌面（微软官方支持方式），无任何恶意行为。  
如误报，请添加信任。介意的话可用源代码 `desktop_restore.pyw` 直接运行  
（需已安装 Python 3，双击 `.pyw` 即可）。

**Q: 重新打包 exe？**  
安装 Python 3.12+ 和 PyInstaller 后，在源码目录执行：  
`py -m PyInstaller --onefile --noconsole --name DesktopRestore desktop_restore.pyw`

## 技术原理（简）

- **读取**：`IFolderView::GetItemPosition` + `IShellFolder::GetDisplayNameOf`
- **写入**：`IFolderView::SelectAndPositionItems(SVSI_POSITIONITEM)`
- 桌面视图通过 `IShellWindows::FindWindowSW(SWC_DESKTOP)` 定位（Win11 24H2 上  
  桌面不再注册进 ShellWindows 集合，必须走这条路径）。
- 旧式工具直接向桌面 ListView 发 `LVM_SETITEMPOSITION` 的方法在 Win10 1809+  
  会被系统忽略，本工具不采用。
